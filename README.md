## Objective

Capture network packets from Linux using tcpdump and analyze
the saved capture with Wireshark.

## Tools

- Linux
- Bash
- tcpdump
- Wireshark
- ping

## Files

- tcpdump_capture.sh — Capture automation script
- capture.pcap — Packet capture generated by the experiment
- output.txt — Text summary of captured packets
- screenshots/ — Project screenshots
